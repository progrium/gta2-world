Help test a GTA2 remake for the browser

These are small experiments for an open-source project that rebuilds GTA2 to run in a web browser. Each one answers a single question, and some of them need a person to try them. Pick any you can do. Each takes between 2 and 20 minutes.

How it works

  1. Open a test. A Tester guide on the right side of the page tells you what to do.
  2. Follow the steps and answer the short questions in the guide.
  3. Press Download results, then Submit on GitHub. That opens a GitHub issue where you drag in the file and press Create. You need a free GitHub account. If you do not have one, send the file to Jeff the way you got this link.

Two tests read files from your own copy of GTA2. Those files are opened inside your browser and are never uploaded anywhere. This site does not host any game files.
